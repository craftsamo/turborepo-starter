# Security policy

## Supported versions

Security fixes target the latest release and the `main` branch. Older releases are not supported.

## Reporting a vulnerability

Report vulnerabilities through [GitHub's private vulnerability reporting](https://github.com/craftsamo/turborepo-starter/security/advisories/new). Reports are shared privately with the repository's maintainers.

Do not open a public issue or pull request for it.

A useful report says:

- what an attacker can do, and what they need to do it
- the version and the part of the project affected
- the steps to reproduce it

## Scope

This policy covers vulnerabilities caused by this repository's code or configuration. For vulnerabilities confined to a third-party dependency, report them to that project's maintainers. If this repository's use or configuration of a dependency creates a vulnerability, report it here.

## Disclosure

Reports are handled on a best-effort basis; response and resolution times are not guaranteed. Public disclosure is coordinated with the reporter. Please keep vulnerability details private until coordinated disclosure.
